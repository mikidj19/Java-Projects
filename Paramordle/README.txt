This is a wordle type game similar to yeezle where you have to guess a mystery song based on things like album and track number and etc
I made mine based on Paramore because they're my favorite band

Instructions will show up in the terminal when you run Paramordle.java

SongData.txt contains information about all the songs on their main 6 albums that is needed for the game
The information is formatted in the following manner 
Song Name/Album Number/Track Number/Length(seconds)/Other Acceptable Names Separated By Commas If Applicable
